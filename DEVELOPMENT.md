# Nana’s House

Responsive, self-contained website concept for a home childcare program.

## Files

- `index.html`: website, styles, original SVG illustration, and demonstration inquiry interaction.
- `.nojekyll`: permits direct static hosting without Jekyll processing.

## Preview

Open `index.html` in a browser, or serve this directory with any static web server. No build tools, external assets, API keys, or dependencies are required.

## Current status

This is a concept for review. The form does not send or save data. The internal marketing and reputation strategy is deliberately excluded from this repository.

Before public launch, confirm the operator identity, program history, city/state, ages, hours, rates, openings, licensing or exemption information, and scope of learning support. Replace illustrative copy with verified details, connect an appropriate inquiry service, and provide the relevant privacy information. Do not collect sensitive child or family information in a general inquiry form.

## Hosting

The files can be deployed to a static website host. Creating or updating this repository does not enable hosting. Preserve repository privacy during development. Review the selected host’s current terms and plan before publication.
